Aula 1 • Semana 22

Agenda e cadastros em memória

Como um programa consegue guardar vários produtos enquanto está funcionando sem usar banco de dados ou arquivo?

🗄️
Analogia: lista = prateleira temporária.

Enquanto o programa está aberto, os itens permanecem disponíveis na memória. Se o programa encerrar sem salvá-los em arquivo, esses dados desaparecem.

[ ]

Lista

Guarda vários valores sob um único nome e permite adicionar novos elementos durante a execução.

0

Índice

Cada item ocupa uma posição. Em Python, a primeira posição de uma lista é o índice 0.

+

append()

Adiciona um novo elemento ao final da lista.

↻

for

Percorre os elementos, permitindo consultar, listar ou processar cada item.

CÓDIGO → O QUE ACONTECE → RESULTADO

Guardando produtos em uma lista

produtos = []

produtos.append("Caneta")
produtos.append("Caderno")
produtos.append("Borracha")

Aula 2 • Semana 23

Médias, faixas e classificação

Agora os dados deixam de ser apenas armazenados: eles são processados para gerar decisões e organizar resultados.

🏆
Analogia: classificação = tabela de campeonato.

Primeiro coletamos resultados, depois calculamos, aplicamos regras e finalmente organizamos uma classificação.

DADOS→CÁLCULO→MÉDIA→CLASSIFICAÇÃO→RESULTADO
MÉDIA

Calcular é uma etapa

O programa processa os dados e produz um valor numérico.

media = (10 + 12 + 8) / 3

Resultado: 10

CLASSIFICAÇÃO

Decidir é outra etapa

Depois, a média é comparada com as faixas de desempenho.

if media >= 30:
    desempenho = "Alto"
elif media >= 10:
    desempenho = "Médio"
else:
    desempenho = "Baixo"
SIMULADOR

Teste as faixas de desempenho

Média 24MédioRegra aplicada: média ≥ 10 e < 30

Funções: separar para reutilizar

FUNÇÃO

Responsabilidade única

def classificar_desempenho(media):
    if media is None:
        return "Sem histórico"
    if media >= 30:
        return "Alto"
    elif media >= 10:
        return "Médio"
    return "Baixo"
entrada↓função↓processamento↓return

Uma função concentra uma tarefa e pode ser reutilizada em vários produtos sem repetir a lógica.

Ranking: ordenar os resultados

O exemplo usa a média armazenada na posição 1 de cada item e organiza do maior para o menor.

SIMULADOR

Antes e depois da ordenação

Resultados

    Código de apoio

    resultados.sort(
    key=lambda item: item[1],
    reverse=True
)

    A expressão item[1] seleciona a média. reverse=True coloca as maiores primeiro.
